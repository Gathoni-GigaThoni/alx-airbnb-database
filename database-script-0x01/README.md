# Airbnb Database Schema

## Overview
This repository contains the complete SQL schema for an Airbnb-like database system. The schema is designed to be normalized (3NF compliant) and optimized for performance.

## Database Structure

### Core Tables
- **users** - User accounts (both hosts and guests)
- **properties** - Property listings with details
- **bookings** - Reservation management
- **payments** - Payment transactions
- **reviews** - User reviews system
- **amenities** - Available property amenities
- **property_amenities** - Property-amenity relationships
- **property_images** - Property image management

### Key Features
- **Normalization**: Full 3NF compliance
- **Constraints**: Comprehensive data validation
- **Indexes**: Optimized for common queries
- **Triggers**: Automated timestamp updates
- **Foreign Keys**: Proper relational integrity
